# Proposals

Applies to a proposal, a bid or a quote cover letter.

## Watch for

- **Swap test.** Replace the client's name with a competitor's. If nothing else has to change, the sentence is generic. Flag it.
- The client's own problem repeated in longer words, with nothing the client did not already say.
- A confident claim about the client's business, market or users that the input does not give.
- A figure with no source. Name the source from the input, or mark it "[source needed]".
- Vague words ("operational bottlenecks", "streamline workflows") where the input names a real file, step or tool.
- One deliverable called by different names ("the pack", "the deliverable", "the output").
- A scope that never says what is not included. Flag it. Never invent the exclusions.
- A timeline with phases and no dates or durations. Flag it. In a rewrite, leave "[date needed]".
- Next steps with no person and no date.
- Every section the same length, or one formula for every section.
- Spelling that differs from the reader's, when the input names the reader's country. A UK client reads "organisation", not "organization".

## Leave alone

- Prices, terms, dates, names, legal clauses and figures the input gives.
- A section that is short because its content is short.
- Required headings a client's request for proposal asks for.
